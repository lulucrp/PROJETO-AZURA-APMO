# 🌌 AZURA

> Aplicativo mobile desenvolvido para a disciplina de Programação de Aplicativos Mobile (APMO).

O **AZURA** é uma aplicação mobile desenvolvida utilizando **React Native** e **Expo**, criada a partir da proposta de um jogo de adivinhação numérica.

O objetivo do aplicativo é descobrir o número escolhido pelo usuário. Para isso, o sistema apresenta diferentes possibilidades e, a cada tentativa, o usuário informa se o número correto é **maior**, **menor** ou se o valor apresentado está **correto**.

O projeto foi desenvolvido como atividade acadêmica do curso Técnico em Informática Integrado ao Ensino Médio.

## 📱 Sobre o projeto

O **AZURA** foi desenvolvido com o objetivo de aplicar conceitos de desenvolvimento de aplicações mobile utilizando **React Native** e **Expo**.

A proposta reúne uma interface interativa com diferentes telas, níveis de dificuldade e sistema de registro das partidas realizadas.

Durante o desenvolvimento, foram utilizados conceitos como:

* Componentização;
* Gerenciamento de estados com React;
* Navegação entre telas;
* Componentes `View`, `Text`, `Pressable` e `ImageBackground`;
* Entrada de dados;
* Manipulação de eventos;
* Geração de números aleatórios;
* Armazenamento local;
* Estilização de componentes;
* Execução e testes em emulador Android.

---

## 🎮 Como funciona?

O aplicativo apresenta um número ao usuário e tenta descobrir o número que ele escolheu.

Durante o jogo, o usuário pode informar se o número apresentado pelo aplicativo é:

⬇️ **Maior** — o número escolhido é maior que o apresentado.

⬆️ **Menor** — o número escolhido é menor que o apresentado.

🎯 **Acertou** — o aplicativo encontrou o número.

A cada resposta, o intervalo de possibilidades é atualizado, permitindo que o aplicativo faça novas tentativas até encontrar o número escolhido.

O aplicativo possui diferentes níveis de dificuldade, aumentando a faixa de números que pode ser escolhida.

# ⚙️ Instalação e execução

## 📋 Pré-requisitos

Antes de iniciar, é necessário instalar:

* [Node.js](https://nodejs.org/)
* [Visual Studio Code](https://code.visualstudio.com/)
* [Android Studio](https://developer.android.com/studio), caso seja utilizado o emulador Android
* Expo Go, caso a aplicação seja executada em um dispositivo Android

Também é necessário ter o projeto **AZURA** baixado no computador.

---

## 1️⃣ Baixar o projeto

Clone o repositório utilizando o Git: https://github.com/lulucrp/PROJETO-AZURA-APMO.git

```bash
git clone https://github.com/lulucrp/PROJETO-AZURA-APMO.git
```

Depois, entre na pasta do projeto:

```bash
cd azura
```

---

## 2️⃣ Instalar as dependências

No terminal, dentro da pasta do projeto, execute:

```bash
npm install
```

Esse comando instala todas as dependências necessárias para executar a aplicação.

---

## 3️⃣ Iniciar o projeto

Após a instalação, execute:

```bash
npx expo start
```

O Expo abrirá o painel de desenvolvimento e permitirá executar o aplicativo.

---

## 📱 Executando no Android

Caso esteja utilizando o **Android Studio com um emulador**, execute:

```bash
npx expo start --android
```

Também é possível executar a aplicação em um celular Android utilizando o **Expo Go**.

---

## 🧹 Limpar o cache

Caso ocorram problemas relacionados ao cache do Expo ou do Metro Bundler, utilize:

```bash
npx expo start -c
```

## 🌙 Identidade visual

A identidade visual do **AZURA** foi desenvolvida a partir de uma estética inspirada no céu noturno e em elementos de mistério.

A interface utiliza principalmente:

* Tons de azul;
* Gradientes;
* Elementos relacionados ao céu;
* Estrelas e detalhes luminosos;
* Formas arredondadas;
* Contraste entre tons claros e escuros.

A proposta visual busca combinar a aparência do aplicativo com a ideia de descoberta presente no jogo.
